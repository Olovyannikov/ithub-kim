# Руководство по стилю заказчика

Источник: `Руководство по стилю.pdf` из `Прил_1_ОЗ_КИМ_09.02.07-3-2027` — приложение к
образцу задания КИМ 09.02.07-3-2027 (одинаковое для ПА и для ГИА ДЭ БУ).

Это **корпоративный стиль заказчика**, по соответствию которому оценивается критерий
«Разработка дизайн-концепций веб-приложений в соответствии с корпоративным стилем
заказчика» — **11 баллов**. Значения ниже воспроизводятся как есть, без подмены на
«похожие» из палитры Mantine.

Заявленная концепция: **надёжность и уверенность**, палитра строгая, но приятная.

## Цветовая схема

| Имя цвета   | HEX-код   | Назначение                     |
| ----------- | --------- | ------------------------------ |
| Голубой     | `#007bff` | основной акцент                |
| Темно-синий | `#0d47a1` | насыщенный акцент, заголовки   |
| Серый       | `#6c757d` | вспомогательный текст          |
| Фон         | `#f8f9fa` | фон страницы                   |
| Выделяющий  | `#ffffff` | фон карточек, выделенные блоки |

## Шрифты

Весь контент — одним шрифтом **PT Sans** (выбран за универсальность, читаемость и
лёгкость восприятия). Файлы шрифта лежат в приложении к заданию (`fonts/PT_Sans.zip`);
`Inter.zip` там тоже есть, но руководство по стилю его не упоминает.

| Элемент                | Размер      | Вид            |
| ---------------------- | ----------- | -------------- |
| Заголовок H1           | 36px        | PT Sans Bold   |
| Заголовки H2 / H3      | 24px / 18px | PT Sans Bold   |
| Основной текст         | 16px        | PT Sans        |
| Вспомогательные тексты | 12px        | PT Sans Italic |

## Что ещё есть в приложении к заданию

- `media/` — 22 изображения (JPG, PNG, WebP), фотографии помещений и логотипы. Именно их
  Задание 2 требует «оптимизировать и улучшить».
- `social/` — 3 файла с иконками соцсетей.
- `fonts/` — PT Sans и Inter в TTF (статические и переменные начертания).

## Что из этого следует для плана

- Палитра и типографика известны → ADR-0008 (Часть 5) проектирует тему Mantine
  **от этих значений**, а не с нуля.
- PT Sans нужно подключить локально из файлов: интернета на площадке нет, Google Fonts
  недоступны.
- Отбор и оптимизация изображений — отдельная задача Части 5: критерий «создания,
  использования и оптимизации изображения для веб-приложений». Поэтому исходники пока не
  копируются в репозиторий целиком: сначала решаем, какие нужны и в каком формате.
