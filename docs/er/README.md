# ER-диаграмма

КИМ, Задание 1: «Не забудьте создать ER-диаграмму в СУБД, а затем сохранить ее в своей
рабочей папке проекта в любом формате».

Обрати внимание на формулировку: диаграмма строится **в СУБД**, по живой базе — не
рисуется руками по памяти. Поэтому в репозитории лежит и то и другое: экспорт из базы
(`schema.png`/`schema.svg`, команда `pnpm erd`) и Mermaid-схема для чтения на GitHub.
На экзамене артефакт из СУБД нужно уметь получить за минуту, поэтому ниже описан и путь
мышкой — он работает на любой машине.

## Диаграмма в репозитории

| Файл                       | Чем получен              | Зачем                                              |
| -------------------------- | ------------------------ | -------------------------------------------------- |
| [schema.png](./schema.png) | `pnpm erd` по живой базе | артефакт для сдачи — его видно без инструментов    |

### `pnpm erd` — диаграмма по живой базе

```bash
pnpm erd
```

Скрипт читает `information_schema` через `psql`, собирает описание графа и рендерит его
в SVG и PNG. Источник — **база, а не код**: таблицы, типы, `NOT NULL`, первичные,
внешние и уникальные ключи, правила `ON DELETE`. Если миграция не применена, её на
диаграмме не будет — это и есть проверка.

Нужны `psql` и `dot` из graphviz:

```bash
brew install graphviz libpq     # macOS
sudo apt install graphviz postgresql-client   # Debian/Ubuntu
```

База берётся из `DATABASE_URL`, по умолчанию `postgresql://kim:kim@localhost:5432/conferences`.

**На экзамене этот путь — не основной.** Graphviz на чужой машине может не оказаться, а
время на установку тратить нельзя. Основной способ — мышкой в СУБД, он ниже и работает
всегда.

## Как получить диаграмму из живой базы

### DBeaver (есть под все ОС, работает офлайн)

1. Подключение к базе → раскрыть `conferences` → `Схемы` → `public`.
2. Правый клик на `public` → **Просмотр диаграммы** (View Diagram).
3. Правый клик на полотне → **Экспортировать диаграмму** → PNG или SVG.
4. Сохранить в `docs/er/` рядом с этим файлом.

### pgAdmin 4

1. Подключиться к базе → выбрать базу `conferences`.
2. Меню **Tools** → **ERD Tool** → кнопка **Generate ERD from database**.
3. **Download image** → сохранить в `docs/er/`.

### MySQL Workbench (если на площадке MySQL)

1. **Database** → **Reverse Engineer**, выбрать схему.
2. Полученную диаграмму сохранить через **File** → **Export** → PNG.

## Проверка, что диаграмма соответствует коду

```bash
pnpm --filter @kim/backend db:schema:log
```

Команда печатает SQL, которого не хватает базе до состояния сущностей. **Пустой вывод
означает, что схема в базе совпадает с кодом** — значит и диаграмма, построенная по базе,
актуальна.
